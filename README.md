# homebrew-tap

Install [jcodex](https://github.com/julien-blanchon/jcodex), a Codex fork with command monitors:

```sh
brew install julien-blanchon/tap/jcodex
```

Supports macOS and Linux on ARM64 and Intel. The formula installs the complete GitHub release package and exposes `jcodex`, so it can coexist with `codex`.

The Update jcodex workflow checks published releases daily and can also be run manually.
